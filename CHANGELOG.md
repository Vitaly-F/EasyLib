# История версий

## 2.7
- Наличие в магазинах: запрос теперь посылается с браузерными заголовками и предварительным заходом на главную магазина за cookies. Это убирает ошибку 403 у магазинов, которые не отвечают «пустому» клиенту.

## 2.6
- Вкладка «Размеры»: контур корпуса теперь рисуется фиолетовым пунктиром, площадки — голубым, шаг — жёлтым, внизу легенда. Раньше контур корпуса и площадки были похожего цвета, и числа путались (например, ширина корпуса 1.60 рядом с шагом 1.40).

## 2.5
- Наличие и цена в магазинах: LCSC, ЧИП и ДИП, Промэлектроника. Кнопка «Магазины» выбирает, какие показывать, и открывает деталь на сайте магазина.
- Базы выбираются выпадающим списком; логотип из верхней панели убран.
- Исправлено: чёрные уголки у скруглённых панелей в Windows; надпись «Точно» обрезалась.

## 2.4
- Импорт готовых библиотек Altium: `.IntLib`, `.SchLib`, `.PcbLib` (например, Altium-вариант со SnapEDA). Детали копируются как есть, вместе с 3D.
- Окно «Очистка»: состав библиотеки, размер каждой детали, удаление деталей и 3D-моделей, копии в папке `Backups` и восстановление из них.
- Общая папка: файл-замок не даёт двум EasyLib писать библиотеку одновременно.
- Повреждённый или перепутанный файл библиотеки больше не перезаписывается; файл «только для чтения» даёт понятное сообщение.
- Русские названия деталей записываются транслитом, а не знаками вопроса.
- Понятные сообщения при ошибках сети и сервера.
- Сверка размеров: расхождение по корпусу показывается как примечание, предупреждение осталось только для шага.
- Тесты (`tests/run_tests.sh`) и сборка через GitHub Actions.

## 2.3
- Вкладка «Размеры»: габариты, шаг, размеры площадок, сверка с названием футпринта, линейка, мм/mil.
- Исправлено: закрашенный корпус символа закрывал графику внутри него. Старые символы чинятся при запуске.
- Номер LCSC, которого нет в поиске EasyEDA, ищется в каталоге LCSC; если CAD-модели нет, программа так и говорит.
- Переключатель «Точно» и сортировка результатов по совпадению с запросом.
- Склад и цена берутся из каталога LCSC.

## 2.2
- Библиотека KiCad как база. Импорт деталей в формате KiCad со SnapEDA, Ultra Librarian и Component Search Engine, подхват из «Загрузок».

## 2.1
- Новый интерфейс, тёмная тема, выбор базы. База «Сообщество» EasyEDA.
- Исправлено: имена выводов пропадали у символа на схеме (2.1); символ `*` в названии ломал библиотеку (2.1.1); обход блокировки 403 (2.1).

## 2.0
